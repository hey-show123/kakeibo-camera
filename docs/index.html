家計簿カメラ

iPhone でレシートを撮るだけ。あなたの Mac の AI（Claude Code など）が、品目・値引き・消費税まで読んで家計簿をつけます。

しくみ

  1. アプリでレシートを撮ると、写真があなたの iCloud Drive に入ります。
  2. あなたの Mac の AI が、読み取りの手順（skill）に従って写真を読み、台帳（CSV）に1品ずつ記帳します。
  3. 記帳した数字が iCloud 経由でアプリに届き、カレンダー・グラフ・予算として出ます。

データはあなたの iCloud と Mac にだけ保存されます。アプリの運営者のサーバーはなく、アカウント登録も要りません。

用意するもの

  • iPhone（iOS 17 以上）と、同じ Apple ID の Mac。両方で iCloud Drive をオン
  • Mac で使える AI（Claude Code がおすすめ。Codex など AGENTS.md を読むものでも可）

Mac や AI が無い場合は、アプリで「この iPhone だけで読む」を選びます。iPhone の中で日付・合計・店名・支払方法を読みます（品目までは読みません。データは iPhone から出ません）。あとで Mac の AI を使い始めれば、受信箱の写真から品目まで読み直せます。

Mac の準備（Claude Code）

ターミナルで1行打ってから、Claude Code に「家計簿カメラの準備をして」と言います。

git clone https://github.com/hey-show123/kakeibo-camera.git ~/.claude/skills/kakeibo-camera

あとは iPhone で撮って、Mac の AI に「レシート読んで」と言うだけです。毎晩自動で読ませる方法は README にあります。

料金

  • 無料：レシートを撮る・今月のレシートの一覧と合計
  • プレミアム：カレンダー・グラフ・収支・予算の「あと使える額」・過去の月
    月額200円／年額1,500円／買い切り3,000円（税込）

月額・年額は、期間の終わる24時間前までに解約しない限り自動で更新されます。解約は iPhone の「設定」→ Apple ID →「サブスクリプション」から。

よくある質問

撮ったのにアプリに出ない
撮った直後は、iPhone で読んだ合計が「iPhoneで読んだ」の印つきで出ます。品目まで入れるには Mac の AI に「レシート読んで」と言うか、毎晩自動で読む予定を入れてください。
「iCloud Drive につながっていません」と出る
iPhone の「設定」→ Apple ID → iCloud で、iCloud Drive をオンにしてください。撮った写真は iPhone に保存してあり、つながると送ります。
読み取りが間違っていた
Mac の AI に「〇日の〇〇のレシートを直して」と頼んでください。台帳はふつうの CSV なので、Numbers や Excel でも直せます。
長いレシートは？
スキャナーで上から順に何ページかに分けて撮ると、AI が1枚のレシートとしてまとめます。
家族の iPhone からも送りたい
iCloud Drive の共有フォルダを使います。手順は SKILL.md の「家族の iPhone からも送るとき」。
機種変更したら？
同じ Apple ID なら、写真も数字も iCloud からそのまま届きます。プレミアムは「設定」→「購入を復元」で戻ります。
