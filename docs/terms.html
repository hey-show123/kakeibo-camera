家計簿カメラ

利用規約

制定日：2026年11月20日

この利用規約（以下「本規約」）は、山﨑 祥平（以下「運営者」）が提供する iPhone アプリ「家計簿カメラ」（以下「本アプリ」）と、その読み取りの手順・道具（以下「skill」）の利用条件を定めるものです。利用者は、本規約に同意したうえで本アプリを利用するものとします。

第1条（本アプリの内容）

  1. 本アプリは、利用者が撮ったレシートの写真を利用者の iCloud Drive に保存し、利用者の Mac で作られた家計簿の数字を表示するアプリです。
  2. 写真の読み取りと記帳は、利用者が自分で用意した AI が skill に従って行います。本アプリ自身は写真を読み取りません。

第2条（利用者が用意するもの）

記帳には、iPhone と同じ Apple ID の Mac、iCloud Drive、Mac で使える AI が必要です。これらの利用料（AI の利用料を含む）は利用者の負担です。これらが無い場合、本アプリは写真の保存と表示しかできません。

第3条（無料の範囲と有料プラン）

  1. 写真を撮ること、今月のレシートの一覧と合計を見ることは無料です。
  2. 有料の「プレミアム」（月額200円・年額1,500円・買い切り3,000円。いずれも税込）を購入すると、AI の家計の見直し・カレンダー・グラフ・収支・予算・過去の月の表示が使えます。料金と内容は App Store の表示が優先します。
  3. 月額・年額は自動更新のサブスクリプションです。お支払いは利用者の Apple ID に請求され、期間の終わる24時間前までに解約しない限り、同じ料金で自動的に更新されます。解約は iPhone の「設定」→ Apple ID →「サブスクリプション」から、いつでもできます。解約しても、支払い済みの期間の終わりまでは使えます。
  4. 返金は Apple の定めに従います。運営者は返金の手続きを行えません。

第4条（skill）

skill は MIT ライセンスで公開しています。利用者は、そのライセンスに従って自由に使い、変えられます。

  • その他、運営者が不適切と判断する行為

第6条（読み取りの正確さ）

  1. AI による読み取りは、写真の状態や AI の性能により誤ることがあります。運営者は、記帳された内容の正確さ・完全さを保証しません。
  2. 本アプリの数字は家計の管理の参考としてお使いください。税務申告や経費精算などに使う場合は、元のレシートと照らし合わせて確認してください。

第7条（サービスの変更・終了）

運営者は、本アプリの内容を変更し、または提供を終了することがあります。データは利用者の iCloud と Mac にあるため、提供を終えた後も利用者の手元に残ります。
